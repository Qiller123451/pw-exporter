# Datamining the composites table (maintainers only)

`pwexport/data/composites.json` (which parts the game scripts attach to which object) was generated by these
scripts from the UrsRel scripts in `Data/Base/Scripts` and checked against the converted models' link nodes.
They were written for a one-off run: adjust the paths at the top of each file (`DATA`, `OUT`, the tech tree JSON
and the folder of converted `.glb` files) before running them again.

    python classes.py      # class .txt files -> classes.json (object -> class name, gfx)
    python links.py        # converted .glb files -> glblinks.json (model -> its link_ nodes)
    python gen.py          # rules + script lookups -> composites.json, object_gfx.json

See `docs/COMPOSITES.md` for what was found, the sources (file:line) and the open questions.
